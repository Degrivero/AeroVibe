# aerovibe-web

Landing page de AeroVibe (Vite + React + TypeScript) con:
- Tema claro/oscuro (toggle en header).
- Idiomas: ES / EN / PT (i18next).
- Rutas legales: `/privacy`, `/terms`, `/cookies`.

## Correr local

```bash
npm install
npm run dev
```

Dev server: `http://localhost:5173`

## Variables de entorno

Copiar `.env.example` a `.env` y setear links (opcional):

- `VITE_APP_STORE_URL`
- `VITE_GOOGLE_PLAY_URL`

## Build

```bash
npm run build
npm run preview
```
